Project Description

Overview

This is a circuit simulator I wrote in Java. It simulates batteries, resistors, capacitors and inductors, so you can design passive circuits and see how they behave.

Features

  • Simulates RC, LC, LR and LRC circuits and graphs the current and voltage of each component over time.
  • Recognizes purely resistive circuits and solves directly for the final voltage, current and power of each component, with no time-stepping needed.
  • Adjustable simulation precision, so you can trade speed for accuracy.
