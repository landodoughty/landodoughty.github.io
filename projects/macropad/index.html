Project Summary

A 20-key programmable macro pad on a custom RP2040 PCB, with hot-swap switches and per-key RGB.

Project Details

  • Programmable keys allow shortcuts, macros, or controls to be customized.
  • Hot-swappable MX switches allows you to customize your typing feel.
  • RGB backlighting allows per-key lighting using WS2812/NeoPixel LEDs
  • MacroPad runs on a custom RP2040 PCB designed in KiCad.
  • Custom 3d printed case provides a sleek, ergonomic look.

Project Description

Overview

This 20-key macro pad runs on the RP2040 microcontroller. Every key is fully programmable for shortcuts, macros or media controls, and it works on Windows, macOS and Linux. It's useful for productivity, creative work and gaming.

Hardware

  • Custom RP2040 PCB designed in KiCad, connected over USB.
  • Hot-swap sockets for MX-style switches, so you can change the typing feel without soldering.
  • Optional per-key RGB lighting with WS2812/NeoPixel LEDs.
  • Custom 3D-printed case, with models free on Printables.
